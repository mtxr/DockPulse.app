# DockPulse - Public Releases

This repository hosts public releases and update feed for DockPulse.

## Download

Visit the [Releases](https://github.com/mtxr/DockPulse.app/releases) page to download the latest version.

## Auto-Updates

DockPulse uses Sparkle for automatic updates. The update feed is available at:
https://mtxr.github.io/DockPulse.app/appcast.xml

## About

DockPulse is a macOS menubar application that aggregates and displays badge counts from various applications.
